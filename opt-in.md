
# Household Manager SMS Sign-Up

## Opt in to Household Manager

Household Manager is a software application that provides automated household-management services to registered users by SMS, including requested information, reminders, scheduling and calendar notifications, task updates, and application-generated responses to user requests.

To opt in, text **START** to **+1 (631) 250-5193**.

By texting START to +1 (631) 250-5193, you expressly consent to receive recurring automated SMS messages generated by the Household Manager application at the mobile number from which you send START.

**Message frequency varies. Message and data rates may apply.**

Consent to receive SMS messages is voluntary.

Reply **STOP** at any time to unsubscribe. Reply **HELP** for help.
