Household Manager SMS Terms & Conditions

Household Manager is a software application that provides automated household-management services to registered users by SMS.

SMS Service
Registered users may interact with the Household Manager application to request information, reminders, scheduling and calendar actions, task management, and other household-management functions. The application may send automated SMS responses, confirmations, reminders, scheduling notifications, calendar updates, and task notifications based on user requests and configured application workflows.

Enrollment
Users enroll in Household Manager SMS by texting START to +1 (631) 250-5193 after reviewing the Household Manager SMS Sign-Up page. By texting START, users expressly consent to receive recurring automated SMS messages generated by the Household Manager application.

Message Frequency
Message frequency varies based on user activity and configured requests. Message and data rates may apply.

Opt-Out
Reply STOP at any time to unsubscribe. No further SMS messages will be sent unless the user opts in again.

Help
Reply HELP for assistance.

Privacy
Mobile information and SMS consent information will not be sold, rented, or shared with third parties or affiliates for marketing or promotional purposes.

Use of the SMS service is also subject to the Household Manager Privacy Policy.
